## 🔧 現在のアルゴリズム詳細

### 1. シグナル計算（エントリー判定）

以下のテクニカル指標を組み合わせて総合スコアを算出：

```
weights = {
    'RSI (14日)': 0.15,
    'RSIダイバージェンス': 0.10,
    '移動平均 (5/20/50/200日)': 0.20,
    'MACD': 0.25,
    'ボリンジャーバンド': 0.10,
    '出来高': 0.10,
    'ROC (Rate of Change)': 0.10
}
```

#### 使用している指標の詳細：

**RSI (Relative Strength Index)**
- 14日RSI
- RSI < 30 で買い、RSI > 70 で売り
- RSIダイバージェンス検出（価格とRSIの乖離）

**移動平均**
- SMA 5日、20日、50日、200日
- ゴールデンクロス・デッドクロス判定
- トレンドフィルター: 50日MA > 200日MA で上昇トレンドと判定

**MACD**
- 標準設定 (12, 26, 9)
- クロスオーバー検出（ゴールデンクロス/デッドクロス）
- ヒストグラムの方向転換検出

**ボリンジャーバンド**
- 20日、±2σ
- 位置（上限/下限からの位置）でシグナル判定

**ケルトナーチャネル**
- ATRベースの動的チャネル
- ボラティリティスクイーズ検出（BB がケルトナー内に収まる = ブレイクアウト待機状態）

**出来高プロファイル**
- 20日平均との比較
- 出来高急増 + 価格上昇 = 強い買いシグナル
- 出来高急増 + 価格下落 = パニック売りサイン

**ATR (Average True Range)**
- ボラティリティ測定
- 損切り幅の動的調整に使用

### 2. エントリー条件

```python
# 買いエントリー条件
1. 総合スコア >= 0.2（市場強気時）
2. 銘柄自体が上昇トレンド（50日MA > 200日MA）
3. 2日連続で買いシグナル（前日スコア >= 0.15）
4. 高値追い回避（前日比 +3% 以下）
5. 押し目買い優先（BB位置 < 0.7）
6. ブラックリストに非該当（2連敗銘柄は20日間買い禁止）
7. 過去実績フィルター（勝率30%以上、平均損益 > -5%）
```

**市場状態による制御**
- S&P500が200日MAを上回る = 強気相場 → 通常買い
- S&P500が200日MAを下回る = 弱気相場 → **完全買い停止**

### 3. ポジションサイジング

```python
# ケリー基準をベースにしたサイジング
base_ratio = max(0.12, kelly_ratio * 1.5)

# 過去実績による倍率調整
if big_wins >= 2: multiplier = 3.0
elif big_wins >= 1: multiplier = 2.5
elif perf_score >= 0.7: multiplier = 1.8
elif perf_score >= 0.5: multiplier = 1.3
else: multiplier = 1.0

# 最大ポジション: 25%、最低購入額: 5万円
# 最大保有銘柄数: 8銘柄
# 同一セクター: 最大2銘柄
```

### 4. イグジット条件（売り）

#### 損切りロジック
```python
# 動的損切り（ATRベース）
base_stop = min(8, atr_pct * 2.5)
adjusted_stop = base_stop * regime_stop_mult  # レジーム調整

# 保有期間ボーナス: 10日ごとに1%緩和（最大2%）
dynamic_stop = min(10, adjusted_stop + holding_bonus)

# ハードストップ: -10%で強制損切り（絶対）
```

#### 利確ロジック
```python
# 段階的利確
if pnl >= 50%: 75%売却
elif pnl >= 30%: 50%売却（5日間隔）

# トレーリングストップ
if pnl >= 50%: 高値から -15%
elif pnl >= 30%: 高値から -12%
elif pnl >= 15%: 高値から -10%
else: 高値から -7%
```

#### 弱気相場時の特別ロジック
```python
# 市場が200日MA割れ時
if pnl >= 5%: 全売却
elif pnl >= 1%: 70%売却
elif pnl <= -3%: 全売却（早期損切り）
```

## ❌ 現在の問題点

### 1. 3月の損失 (-3.71%)

**分析結果：**
- 2025年3月初旬にS&P500が下落開始
- 2月末までに積み上げた利益が一気に吹き飛んだ
- 弱気相場への移行を検知してから売却するまでにラグがあった
- 損切りが遅かった取引が複数存在

**失敗例：**
```
- SKYW: -10.0%（ハードストップ到達）
- NNE: -10.0%（ハードストップ到達）
- CCJ: -10.0%（ハードストップ到達）
```

### 2. 4月の停滞 (+0.00%)

**分析結果：**
- 弱気相場と判定されて買い停止
- 3月の損失から回復できず
- 相場回復時のエントリーが遅れた

### 3. 早期警戒システムの失敗

v9.3で試みた「早期警戒シグナル」：
- モメンタム悪化、RSI反転、MACDピークなどで早期売却
- **結果：過剰な売却でリターンが悪化（+19% → +13%）**
- 「損失前に売る」より「通常の売却タイミングの方が良い」ことが判明

## 💡 改善したい点

### 1. 3月のような急落時の対応
- 弱気相場への移行をより早く検知したい
- 損切りラインに到達する前に逃げる方法
- ただし、ノイズで過剰に売却しないバランス

### 2. 相場回復時の再エントリー
- 4月のような回復期に素早く市場に戻りたい
- 現状は「完全買い停止」が長引きすぎる

### 3. 全体的なリターン向上
- 年間+19%を+25%以上に
- シャープレシオ1.62を2.0以上に
- 最大ドローダウン5.9%を維持または改善

### 4. 銘柄選定の改善
- 勝率55%を60%以上に
- 大勝ち(+20%以上)の頻度を増やしたい
